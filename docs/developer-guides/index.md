They describe recommended practices unless a guide identifies a project requirement.

## Improve These Guides

If a guide does not work in your environment, investigate the problem and correct the guide.
You can use Codex or a similar development tool to help diagnose the problem and prepare the change.
Verify the corrected instructions in your environment, then submit a pull request with the fix.
